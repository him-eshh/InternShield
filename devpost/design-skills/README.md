# Design skill references

Shortlist pulled from https://github.com/bergside/awesome-design-skills (MIT, TypeUI). Plain files, no CLI run.
Each folder has `SKILL.md` (style foundations and rules) and `DESIGN.md`. They are reference presets, not code; InternShield's tokens live in `app/theme.css`.
Used as vocabulary for the redesign in `devpost/design-direction.md`: terracotta/editorial (warm cream, display serif), lingo (tactile bottom-border buttons, progress), friendly (soft pastels), plus bento, expressive, impeccable, paper, refined, riso, spacious, storytelling.
