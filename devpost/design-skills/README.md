# Design skill references

Historical shortlist pulled from [bergside/awesome-design-skills](https://github.com/bergside/awesome-design-skills) (MIT-licensed source project). Plain reference files, not application code. The project also has local copies of Levels, Tetris, and Sketch in `.agents/skills/{levels,tetris,sketch}`.
Each folder has `SKILL.md` (style foundations and rules) and `DESIGN.md`. They are reference presets, not code; InternShield's tokens live in `app/theme.css`.
The selected combination for InternShield is **Levels** for interaction hierarchy, **Tetris** for block-like progress and evidence structure, and **Sketch** for paper annotations. See the owner update at the top of `devpost/design-direction.md`. The earlier terracotta/editorial/lingo references remain research vocabulary, not the selected design system. InternShield retains its own coral/teal/violet tool palette and separate risk colors.
