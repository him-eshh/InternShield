## Design system (approved by Himesh on Oct 25, final; tokens live in ONE swappable theme file, `app/theme.css`)
Himesh rejected v2's "Calm Instrument" one-blue look (findings 06 §2 Direction A and its "no gradients / one accent" rules are REPLACED by this section; 06 §4 motion specs, §9 craft checklist, §10 accessibility and §15 pitfalls other than the color rules still apply).
- **References:** Linear (polish, motion, dark elevation from one hue), Raycast (vivid per-command color, crisp icons), Duolingo (session flow, progress bars, end-of-session moment), Notion (home and onboarding clarity). Name these in code comments of `app/theme.css`, not in the UI.
- **Tool color identities**, carried through each tool's icon, nav tab (active state), primary buttons, focus/highlights and illustration: **Check = warm coral**, **Tailor = green** (lean emerald/teal so it never reads as the risk "low" green), **Practice = violet**. Tracker and Profile use the ink/neutral brand color. Each accent has light + dark values, a soft tint (backgrounds) and an on-accent text color, all WCAG AA (text >= 4.5:1, UI marks >= 3:1).
- **Risk colors are reserved:** red (high), amber (medium), green (low) appear only on risk results (ring, level icon, tags, marks), always with an icon + words, never color alone. Coral must be visibly distinct from risk red (more orange/pink, lighter); if a report screen shows both, the report's chrome uses neutral, not coral.
- **Canvas:** warm off-white light theme (e.g. #FBF8F3 page, white cards, warm grey borders). Dark theme: deep ink-navy (e.g. #0D1220 page with 3-4 elevation steps derived from one hue), never pure black, no shadows in dark (use surface steps).
- **Type:** Bricolage Grotesque (display, headings; next/font/google, OFL) + Inter (body, UI; next/font/google). Tabular numbers on scores, counters, timers.
- **Depth and texture:** cards with gentle layered shadows (light theme), soft gradient mesh only in the home hero (and optionally faint on empty states), no glow borders, no blurred blobs everywhere, no emoji bullets.
- **Icons:** lucide-react only (one stroke width, 1.75 or 2 everywhere). **Illustrations:** one small hand-made SVG illustration per tool (Check, Tailor, Practice) plus one for Profile/empty states, drawn in the tool's colors, used on Home and empty states. Inline SVG components, no stock art, no AI-generated images.
- **Motion (motion/react, `MotionConfig reducedMotion="user"`):** page transitions between tabs (fast crossfade + 8px slide, <= 250ms), staggered card reveals on Home and lists (once, on mount; never scroll-reveal), score ring counts up on reveal, changed resume lines glow briefly when accepted/rejected, interview per-round progress bar, a small end-of-session celebration (tasteful, <= 1.2 s, no confetti flood; skip under reduced motion), hover/press states on cards and buttons. Under reduced motion everything is immediately in its final state.
- **Responsive:** designed (not just squeezed) at 390, 768 and 1440. Mobile: bottom tab bar with icons + labels, 44px touch targets, no sideways scroll at 320. Desktop: top nav (or left rail) with icons + labels; content widths that suit each screen (coding layout wide, forms narrow).
- **Copy:** short, second person, specific, verb first. No filler ("Unlock", "Supercharge", "Seamless"), no fake stats.
